# Technologies Used
Charles Bakery Store was built using modern frontend technologies:
- **React** for building the user interface
- **React Router** for client-side navigation
- **Shopping cart library** for managing cart state and checkout logic
- **CSS** for styling the components and layout

This was my first time using React in a class project, and I was excited to apply what I had recently learned from a React course on Scrimba. This project was my introduction to building a modern frontend using components, routing, and third-party libraries to enhance functionality.

# Purpose and Goal
The main purpose of Charles Bakery Store was to create a fully functional online storefront for my frontend web development class. The application allowed users to browse bakery items, add them to their cart, and simulate a checkout experience. Beyond just fulfilling the course requirements, this project was a chance for me to practice structuring a React application in a real-world context.

The project challenged me to think about user experience, component architecture, and state management - all fundamental concepts that would become crucial in my development career.

# Technical Hurdles (and How They Were Solved)
One of the first hurdles I encountered was learning how to properly structure React components so that the code stayed organized and reusable. By breaking down the app into smaller pieces (such as product cards, navigation, and the shopping cart), I was able to keep the project maintainable and easy to understand.

Integrating the shopping cart library was another challenge, since it required me to understand how React handles state and props. This gave me valuable practice in managing application state and passing data between components - concepts that seemed abstract in tutorials but became concrete through hands-on implementation.

Learning to manage the flow of data from product listings to cart state to checkout was particularly educational, as it taught me about React's unidirectional data flow and the importance of thinking about where state should live in the component tree.

# Lessons Learned
This project was an important stepping stone in my journey as a frontend developer. I gained confidence in using React and React Router, and I began to see how external libraries can speed up development without sacrificing flexibility. The experience of building a complete user interface from scratch was incredibly rewarding.

Most importantly, Charles Bakery Store laid the groundwork for my future use of React. What started as a simple class assignment became the foundation for skills that I would carry into larger, more complex projects down the road. The project solidified my interest in frontend development and showed me the power of component-based architecture.
